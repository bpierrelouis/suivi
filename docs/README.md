## Convention de lecture

Le compte rendu consolidé sert de référence de travail ; sa validation formelle reste à renseigner. Les documents dérivés ne transforment pas ses points « envisagés » ou « à préciser » en décisions acquises.

- **Retenu au compte rendu** : besoin explicitement décrit dans la source.
- **Proposition** : organisation, précision ou exigence complémentaire soumise à validation.
- **À arbitrer** : comportement non défini, suivi par un identifiant `Q-xx`.

Les identifiants `US-xx` désignent les stories, `RG-xx` les règles, `REC-xx` les scénarios de recette et `Q-xx` les questions. Le backlog est la référence pour la priorité et l’état d’avancement ; les stories sont la référence pour les critères d’acceptation. Les liens vers les stories utilisent des ancres stables.

## Entretien du dossier

À chaque arbitrage client, renseigner la décision, son auteur et sa date dans le registre, puis modifier ensemble les stories, règles, données et scénarios concernés. Ne marquer une story terminée qu’après vérification de ses critères et consignation du résultat de recette. Les numéros existants sont conservés même si un élément est abandonné.

Les images dans `Maquette Simple/` sont des supports existants ; leurs écarts sont consignés dans le document de parcours. Le compte rendu et ces images sont conservés comme sources.
